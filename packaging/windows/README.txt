AIP WEEK 2 ALLOCATOR - HOW TO USE
=================================

1. Extract the entire ZIP file into a folder.
2. Open the extracted AIP-Week2-Allocator folder.
3. Double-click START.bat.
4. Wait for your browser to open at http://localhost:3000.
5. Upload the Excel files and use the application normally.
6. When finished, double-click STOP.bat.

The application runs locally on this laptop. Employee information is not sent to
an external service, and internet access is not required after the ZIP is built.

Keep this folder intact. Do not move START.bat or individual files outside it.

If the application does not start, check the logs folder and contact your
application administrator. A company-managed laptop may require IT approval to
run unsigned internal software. Do not bypass company security warnings.
